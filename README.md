# 📱 MoneyCare – Quản Lý Chi Tiêu Cá Nhân (Phase 1)

Dự án Web App Quản Lý Chi Tiêu Cá Nhân phát triển bằng React + TypeScript + Vite + Tailwind CSS.

## 🚀 Hướng dẫn khởi chạy nhanh

1. Mở Terminal trong thư mục `web`:
```bash
cd web
npm install
npm run dev
```

2. Mở trình duyệt Chrome truy cập địa chỉ: `http://localhost:5173/`

3. Màn hình mặc định:
   - Màn hình Splash (`/splash`): Tự động chuyển hướng sang Dashboard sau 1.9s.
   - Màn hình Home Dashboard (`/home`): Quản lý số dư, thu nhập, chi tiêu, ngân sách tháng và giao dịch gần đây.
